# Church OMS Brand Assets

Web-ready PNG brand assets for use across the Church OMS application and marketing surfaces.

## Recommended usage

- `church-oms-logo-primary-transparent.png` - default full logo on light or neutral UI surfaces.
- `church-oms-logo-white-transparent.png` - full white logo for dark backgrounds.
- `church-oms-icon-primary-transparent.png` - compact brand mark for the sidebar, mobile UI, loaders and small placements.
- `church-oms-icon-white-transparent.png` - compact white mark for dark backgrounds.
- `church-oms-favicon.png` - browser favicon.
- `church-oms-app-icon-*.png` - app icon variants for light, dark, blue and white backgrounds.
- `church-oms-logo-primary-light.png` and `church-oms-logo-primary-dark.png` - background-baked full logo variants.
- `church-oms-icon-primary-light.png` and `church-oms-icon-primary-dark.png` - background-baked icon variants.
- `church-oms-logo-monochrome-dark.png` and `church-oms-logo-monochrome-white-on-dark.png` - monochrome applications.

These files are intentionally kept under `public/brand/` so application code can reference them directly as `/brand/<filename>`.
